# Как внести вклад

Скилл — это текст и немного кода. Приветствуются новые русские маркеры, примеры «до и после», исправления формулировок и новые способы установки.

## Правила для маркеров

1. **Маркер описывает явление, а не слово.** «Инфляция значимости» — маркер, «слово является» — симптом.
2. **Пример должен быть русским.** Не переводите английские примеры: нужны конструкции, которые встречаются в русских текстах.
3. **Пара «до и после».** Без второго примера маркер бесполезен: непонятно, что делать.
4. **Номер в конце.** Нумерация сквозная, новый маркер получает следующий номер и попадает в конец своего слоя.
5. **Не дублируйте.** Проверьте, что явление не описано в соседнем разделе.

## Правила для текста самого скилла

Скилл про нейрослоп не должен быть нейрослопом. Перед отправкой прочитайте свой текст и проверьте:

- нет абзацев-вердиктов и финальной морали;
- нет антитезы «не X, а Y» в начале абзаца;
- каждое утверждение проверяемо или явно помечено как мнение;
- примеры конкретные, а не «компания N».

## Локальная проверка

```bash
python scripts/validate.py
```

Скрипт проверяет frontmatter, длину `SKILL.md`, битые ссылки, нумерацию каталога, JSON и совпадение версий в пяти файлах.

Проверьте установку в тестовую папку:

```bash
cd cli
python -m antislop.cli install --source .. --dir /tmp/man-test --force
python -m antislop.cli uninstall --dir /tmp/man-test
```

Соберите артефакты:

```bash
python scripts/package.py --out dist
./installer/windows/build.ps1
```

## Версии

Версия живёт в пяти местах и должна совпадать:

- `skills/anti-neuroslop/SKILL.md` → `metadata.version`
- `package.json`
- `cli/pyproject.toml`
- `.claude-plugin/plugin.json`
- `.claude-plugin/marketplace.json`

`validate.py` падает, если версии разошлись. При выпуске обновите `CHANGELOG.md` и поставьте тег `vX.Y.Z`.

## Коммиты и pull request

- Ветка от `main`, атомарные коммиты в повелительном наклонении.
- В описании PR: что изменилось, зачем, как проверяли.
- Если меняется поведение установки, обновите `docs/install.md` и `README.md`.
- Если добавлен маркер, обновите счётчик в `README.md`, `docs/how-it-works.md` и `CHANGELOG.md`.
