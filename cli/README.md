# antislop

Установщик скилла [MAN — My Anti-Neuroslop](https://github.com/crruton/MAN).

```bash
pipx install "git+https://github.com/crruton/MAN.git#subdirectory=cli"
antislop install
```

Команды: `install`, `uninstall`, `doctor`, `version`. Подробности — в [README репозитория](https://github.com/crruton/MAN#установка).
